# EventHub – Event Registration Website

## About

EventHub is a simple event registration website built with HTML, CSS, and JavaScript. It allows visitors to view upcoming events and register for their preferred event.

## Technologies Used

* HTML5 – Website structure
* CSS3 – Styling and responsive layout
* JavaScript – Interactivity and form validation

## Features

* Displays upcoming events.
* Shows event dates, venues, and descriptions.
* Provides a registration form.
* Validates required fields.
* Displays a success message after submission.

## Project Files

* `index.html` – Website structure
* `style.css` – Website styling
* `script.js` – Website functionality

## How to Run

Open `index.html` in your web browser.

## Note

This is a frontend practice project. Registrations are not saved permanently.
